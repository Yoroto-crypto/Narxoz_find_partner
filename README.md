# Narxoz Team Finder — бот для поиска сокомандников

Минимальный Telegram-бот: люди заполняют короткую анкету (кто, тема,
навыки, язык общения, кого ищут) и листают/ищут анкеты других. Хранилище —
один файл SQLite, создаётся сам при первом запуске. Хостить можно бесплатно.

## 1. Получить токен бота

1. В Telegram открой **@BotFather**
2. `/newbot` → придумай имя и username (должен заканчиваться на `bot`)
3. BotFather пришлёт токен вида `123456:ABC-DEF...` — сохрани его

## 2. Запуск локально

```bash
cd team_finder_bot
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

export BOT_TOKEN="твой_токен_сюда"   # Windows (PowerShell): $env:BOT_TOKEN="..."
python bot.py
```

Бот запустится и будет работать, пока открыт терминал. Открой бота в
Telegram и нажми **Start**.

## 3. Бесплатный хостинг 24/7 (чтобы не держать свой компьютер включённым)

Любой из этих сервисов даёт бесплатный тариф, достаточный для одного бота:

- **Railway.app** — залить репозиторий с GitHub, задать переменную
  окружения `BOT_TOKEN` в настройках проекта, `Start Command: python bot.py`
- **Render.com** — Background Worker, тот же принцип
- **PythonAnywhere** — можно запускать как always-on task на бесплатном тарифе

Во всех трёх: залей эти 3 файла в GitHub-репозиторий → подключи репозиторий
на сервисе → добавь переменную окружения `BOT_TOKEN` → деплой.

## 4. Команды бота

- `/start` — при первом запуске сначала спрашивает язык интерфейса
  (Русский / Қазақша / English), потом создаёт/обновляет анкету, в конце
  анкеты — выбор способа связи (Telegram / телефон / email)
- `/language` — сменить язык интерфейса бота в любой момент
- `/browse` — листать анкеты других людей (кнопки «Назад» / «Дальше»)
- `/find <слово>` — поиск по навыку/теме/языку, например `/find python` или `/find қазақша`
- `/myprofile` — посмотреть свою анкету; там же кнопки «✅ Нашёл(-ла) команду» и «🗑 Удалить»
- `/found` — отметить, что команда уже найдена: анкета исчезает из `/browse` и `/find`,
  но данные не удаляются
- `/reopen` — вернуть анкету обратно в ленту поиска
- `/delete` — удалить анкету навсегда

## 5. Посмотреть базу данных самому (не через бота)

Команда `/export` (доступна только тебе как админу) присылает файл
`team_finder.db` прямо в Telegram — дальше открываешь его на компьютере
любой программой для просмотра SQLite.

1. Узнай свой Telegram user id — напиши в Telegram боту **@userinfobot**,
   он пришлёт твой числовой id
2. В Railway: Variables → New Variable → имя `ADMIN_USER_ID`, значение —
   твой id (просто число, без кавычек)
3. Дождись передеплоя (Railway сделает это сам после сохранения переменной)
4. Напиши своему боту `/export` — придёт файл `team_finder.db`
5. Открой его на компьютере в **DB Browser for SQLite**
   (бесплатно, dbbrowser для Windows/Mac: sqlitebrowser.org) — там видно
   таблицу `profiles` целиком, как в Excel. Либо расширение
   **SQLite Viewer** в VS Code — открывается прямо в редакторе

Без переменной `ADMIN_USER_ID` команда `/export` отвечает "недоступно"
всем, включая тебя — это защита, чтобы файл базы не смог скачать кто-то
чужой, узнав про команду.

## 6. Бэкап и восстановление базы

Важно понимать: **обычный перезапуск или редеплой (например, после заливки
новых файлов на GitHub) базу не стирает** — она хранится в файловой системе
контейнера Railway и переживает рестарты. Она пропадает только если сервис
или весь проект **удалить и создать заново**.

Поэтому бэкап нужен именно перед такими операциями (пересоздание сервиса,
переезд на новый проект/тариф и т.п.), а не перед каждым обычным
перезапуском:

1. Перед рискованной операцией — сделай `/export`, сохрани присланный файл
   `team_finder.db` у себя на компьютере
2. Сделай что планировал (пересоздай сервис, перенастрой проект и т.д.),
   заново задеплой бота
3. Напиши боту `/import` — он попросит прислать файл
4. Прикрепи и отправь тот самый `team_finder.db`, который сохранил на шаге 1
5. Бот подтвердит восстановление — все анкеты вернутся

`/import`, как и `/export`, доступна только тому, чей id указан в
`ADMIN_USER_ID`.

## 7. Как обновить бота дальше

Да, всё меняется через замену файлов в GitHub — установка не нужна.
Просто открой свой репозиторий → Add file → Upload files → перетащи
обновлённый `bot.py` (и другие изменённые файлы) → Commit changes.
Railway сам увидит изменение в репозитории и передеплоит бота за
1-2 минуты. Существующие анкеты в базе при этом не теряются — новые
поля (например, `contact_type`/`contact_value`) у уже созданных анкет
просто останутся пустыми, пока человек не пройдёт `/start` заново.

Важно: язык интерфейса (кнопки, подсказки, подписи анкеты) — это отдельная
настройка от "языка общения в команде", который задаётся в конце анкеты и
нужен, чтобы искать тиммейтов, говорящих на нужном языке.

## 5. Как раскрутить, чтобы не выглядело "личным" проектом

- Назови бота нейтрально (`@narxoz_team_finder_bot`), а не своим именем
- Первый пост в чатах курса — не "помогите найти команду", а
  "запустил бота для поиска сокомандников на дипломы/курсовые/хакатоны,
  залетайте, если тоже ищете"
- Попроси 2–3 знакомых с разных специальностей и курсов зарегистрироваться
  первыми — пустая лента отпугивает
